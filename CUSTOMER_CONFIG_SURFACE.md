# Customer configuration surface

This document defines **what operators can configure without editing application source**, what **still required source or fork** historically, and the **remediation plan** for gaps.

**Short list of paths that may still need edits:** **`FILES_REQUIRING_SOURCE_EDITS.md`**.

---

## 1. Official customer-facing configuration (no code edits)

| Surface | Mechanism | Notes |
|---------|-----------|--------|
| **Secrets & URLs** | Root **`.env`**, optional **`.env.internal`** | Telnyx, Postgres, JWT, public URLs, registry/version — see **`.env.example`**, **`CONFIG_MATRIX.md`**. |
| **Per-tenant behavior** | Control plane **UI / API** → Postgres → Redis **`tenantcfg:*`** | Prompts, DIDs, TTS/STT overrides, workflows — schema **`shared/src/runtimeContract.ts`**. |
| **Branding (admin / portal / owner)** | **`BRAND_*`** env vars → **`GET /api/branding`** → React provider / **`public/apply-branding.js`** | Emblem (`BRAND_LOGO_URL`), wordmark (`BRAND_WORDMARK_URL`), titles, taglines, and portal footer link. Defaults use the official veralux.ai assets. |
| **Installer online API** | **`INSTALLER_CONFIG_API_URL`**, **`INSTALLER_SIGNUP_URL`** env vars before **`./install.sh`** | Replaces hardcoded vendor API/signup URLs in **`install.sh`**. |
| **Telnyx connection label** | **`TELNYX_CONNECTION_DISPLAY_NAME`** | Shown in Telnyx when creating a new connection. |
| **Default LLM preamble (fallback)** | **`DEFAULT_RECEPTIONIST_SYSTEM_PREAMBLE`** | When tenant has no `systemPreamble` in DB. |
| **TTS preview phrase** | **`TTS_PREVIEW_SAMPLE_TEXT`** | Admin TTS preview default text. |
| **Workflow email From** | **`SMTP_FROM`** | Avoids vendor-specific default in code. |
| **Workflow SMS default body** | **`WORKFLOW_SMS_DEFAULT_MESSAGE`** | When step omits message. |
| **Process log line** | **`PRODUCT_DISPLAY_NAME`** | Startup banner in control plane. |
| **Installer bootstrap user** | **`INSTALLER_USERNAME`** / **`INSTALLER_PASSWORD`** / **`ADMIN_CONSOLE_EMAIL`** | Env bootstrap. Staff can change email/password in **Admin → Settings → Your sign-in** (stored hashed in `console_credentials`). Owners change theirs in **Portal → Settings**. |
| **Custom static assets** | **`docker-compose.override.yml`** bind-mount over **`control-plane/public`** | Operator-owned; not generated by this repo. |
| **Runtime audio / STT** | **`.env`**, tenant DB, **`AUDIO_*`** | Already documented elsewhere. |

**API:** `GET /api/branding` returns JSON consumed by the React console and static HTML shells (no rebuild required when only env changes).

## 2. Files that *used to* imply source edits (remediated or neutralized)

| File / area | Previous issue | Remediation |
|-------------|----------------|-------------|
| **`control-plane/public/legacy/admin.html`**, **`portal.html`**, **`owner.html`** | Hardcoded VeraLux logo URLs and copy | Official VeraLux emblem is bundled by default; runtime overrides via **`apply-branding.js`** + **`BRAND_*`**. Structural/CSS changes still need HTML or mount. |
| **`install.sh`** | Hardcoded **`api.veralux.ai`** / signup URL | **`INSTALLER_CONFIG_API_URL`**, **`INSTALLER_SIGNUP_URL`**. |
| **`scripts/seed-default-runtime-config.json`** | Customer-specific DID / URL / secret placeholder | Neutral **`+15551234567`**, **`your-domain.com`**, explicit **`REPLACE_*`** placeholder. |
| **`cloudflared/config.yml`** | Customer hostnames + tunnel UUID | Marked **example only**; **`example.com`** hostnames; **`REPLACE_WITH_TUNNEL_UUID`**. |
| **`control-plane/src/telnyx.ts`** | `"VeraLux Voice"` | **`TELNYX_CONNECTION_DISPLAY_NAME`**. |
| **`control-plane/src/receptionist.ts`** | VeraLux in default preamble | **`DEFAULT_RECEPTIONIST_SYSTEM_PREAMBLE`** + vendor-neutral default string. |
| **`control-plane/src/ttsPreview.ts`** | VeraLux in preview phrase | **`TTS_PREVIEW_SAMPLE_TEXT`**. |
| **`control-plane/src/automations/actions.ts`** | `noreply@veralux.ai`, VeraLux SMS text | **`SMTP_FROM`**, **`WORKFLOW_SMS_DEFAULT_MESSAGE`**, neutral fallbacks. |
| **`control-plane/public/owner.html`** (JS string) | “VeraLux account” | Product-neutral **“your account”**. |

## 3. Files that may still require edits (advanced / optional)

| File / pattern | When a customer must touch it |
|----------------|------------------------------|
| **`control-plane/public/admin-neural.css`**, layout in **`.html`** | Deep visual rebrand (fonts, layout), beyond logo/title/footer. |
| **`control-plane/public/dev-console.html`** | Dev tool title/branding — not wired to **`apply-branding.js`** (low priority). |
| **`docker-compose.override.yml`** | Extra volumes, resource limits, **digest-pinned** `image:` overrides. |
| **`nginx/`** (if used) | TLS termination, host routing. |
| **`veralux-audio-stack/**`**, **`Dockerfile*`** | Custom model pipelines — not normal onboarding. |
| **Forked registry / image names** | If not using **`REGISTRY`/`VERSION`** contract — unsupported pattern per **`UNSUPPORTED_PATTERNS.md`**. |

## 4. Remediation plan (phases)

| Phase | Scope | Status |
|-------|--------|--------|
| **A** | Branding via env + **`/api/branding`** + client script | **Done** |
| **B** | Neutral defaults in seed/config examples; installer URL env | **Done** |
| **C** | Telnyx / workflow / LLM fallback copy via env | **Done** |
| **D** | Optional **`install.sh`** auto-`source` of `.env` for installer URLs | *Deferred* — risky if `.env` is non-shell-safe; use **export** before install. |
| **E** | **CSS variables** driven by **`/api/branding`** (primary color) | *Future* |
| **F** | **`dev-console.html`** branding hook | *Future* |
